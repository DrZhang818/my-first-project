# E（枚举 + 圆方树 + 构造）

* 题意：给定一个$N$个节点$M$条边的无向连通图，判断图中所有长度 $\geq 3$的简单环的长度是否相等
* 范围：$N \in [1,5 \times 10^5]$，$M \in [0,5\times 10 ^ 5]$，保证无自环和重边
* 关键思考：
  * 本题为判断与结构分析类题目，常用思考方式为：
    1. 手玩找规律
    2. 寻找**不变量**与**单调性**
    3. 转化标准模型
    4. 极端假设与反证法
    5. 归纳构造法
  * 首先思考简单环的性质，一个简单环必然完整地处于图中的某个**点双连通分量**内部，因此，分析整张图的结构就可以分解为分析各个点双的结构
  * 于是问题就被分解为了两步：
    * 判定每个$BCC$内部的所有环是否满足环长相等
    * 判定各个$BCC$是否都有统一的环长
  * 问题的核心就在于：如何判定每个$BCC$内部所有环的长度是否相等
  * 考虑$BCC$的生成过程，根据**耳分解定理**，所有的双连通图，都是通过在一个“基础环”上不断添加“耳朵”而搭出来的。
    * 耳朵：在一个现有的图$G$上，我们要添加一条路径$P$
      * 这条路径的**两个端点**必须已经在图$G$中
      * 这条路径的**中间节点（如果有的话）**必须是全新的点，不在图$G$中
      * 这条路径的两个端点不能重合
  * 考虑任意一个大小至少为$3$的点双，从中任选一个环作为初始结构$G_0$，接下来我们通过逐步加“耳”的方式来构建整个$BCC$
  * 想象在一个圆上，在其内部加一条边，如何让添加后的图满足环长相等呢？显然我们新加的边必须平分这个圆，且新加的边的长度恰好为圆周长的一半
  * 环只是个离散版的圆，道理完全相同，加上一条边后，我们就得到了$G_1$，而$G_1$合法时，可以视为$3个G_0$
  * 经过推演，我们会发现后续添加的耳必须完全模仿第一条耳的行为，即端点和长度都要一致。第一个耳所取得两个端点称为“极点”，长度$L = 环长 / 2$，这种图被称为$Theta \ Graph:=$ 两个极点 + 多条并联等长路径
  * 因此，一个$BCC$是合法的，当前仅当$BCC$边数$ < 2$，或为一个简单环，或为$Theta \ Graph$
  * 如何判定一个$BCC$是否是$Theta \ Graph$呢？
    * 我们可以先看是否恰有两个极点（度数 > 3）
    * 然后运用$XOR \ trick$遍历两个极点间的所有路径，并计算长度，当长度全部一致时判定成功
  * 代码实现时可以借助圆方树完成点双缩点
