### Problem: [100939. 交替删除操作后最后剩下的整数](https://leetcode.cn/problems/last-remaining-integer-after-alternating-deletion-operations/description/)

### 思路：

本题是约瑟夫环问题的变体

> 约瑟夫环问题：$n$ 个人站成一圈轮流报数，报到 $k$ 的出队，问最后剩下的人是谁	

直接正向进行模拟显然会超时，因此我们考虑能否进行倒推

观察 $n = 6$ 的游戏过程：

* $[1,2,3,4,5,6]$，向右删
* $[1,3,5]$，            向左删
* $[1,5]$，                向右删
* $[1]$，                    向左删，游戏结束

这启发我们用（元素个数，操作方向）来描述一个局面

然而，这样定义出的局面并不唯一，例如 $[1,3,5]$ 向右删 与 $[2,4,6]$ 向右删 是同一个局面，但得到的答案却不一致

幸运的是，一个局面最终会剩下第几个数是唯一确定的，我们可以完全忽略一个局面的具体数值，从求解答案的**值**变为求解答案的**下标**

* 记 $x:=$ 元素个数，$tag:=$ 操作方向（ $1$ 表示从左向右，$0$ 表示从右向左）

* 用 $f(x,tag)$ 表示局面 $(x,tag)$ 对应的答案**下标**
* 初始局面 $f(1,0/1) = 1$

* 不难发现，一个局面 $f(x,tag)$ 的后继是 $f(\lceil \frac{x}{2} \rceil, tag \oplus 1)$，我们要做的就是建立**下标**转移方程
* 当 $x$ 为奇数时：
  * 此时 $tag = 0/1$ 的效果是一样的，都是把原局面的奇数下标 $i$ 映射到新局面下标 $\lceil \frac{i}{2} \rceil$。反过来，新局面的下标 $i$ 就对应原局面下标 $2 \cdot i - 1$ 
  * 因此 $f(x,tag) = f(\lceil \frac{x}{2} \rceil,tag \oplus 1) \times 2 - 1$
* 当 $x$ 为偶数时：
  * 若 $tag = 1$，效果和奇数一样，都是保留所有奇数下标
  * 若 $tag = 0$，此时留下的就是原局面的所有偶数下标，把原局面的偶数下标 $i$ 映射到新局面的 $\frac{i}{2}$。反过来，新局面的下标 $i$ 就对应原局面的下标 $2 \cdot i$
  * 因此 $f(x,0) = f(\lceil \frac{x}{2} \rceil,1) \times 2 - 1$，$f(x,1) = f(\lceil \frac{x}{2} \rceil,0) \times 2$

每次操作会将规模减半，因此时间复杂度为 $O(log_2n)$

推荐读者练习：

* [P8671约瑟夫环](https://www.luogu.com.cn/problem/P8671) （倒推）
* [CF2169D2](https://codeforces.com/contest/2169/problem/D2) （正推）

```C++
using ll = long long;
class Solution {
public:
    ll lastInteger(ll n) {
        auto dfs = [&](this auto &&self, ll x, int tag) -> ll {
            if(x == 1) {
                return 1;
            }
            return self(x + 1 >> 1, tag ^ 1) * 2 - (x & 1 | tag & 1);
        };
        return dfs(n, 1);
    }
};
```
