# B

对于任意一种合法集合 $S$ ，如果 $S$ 中存在小于等于 $⌊R / 2⌋$ 的数，我们可以对其不断 $× 2$，直到大于 $⌊R / 2⌋$ 为止。不难发现，经过映射后的集合仍是合法集合。

问题转化成：从 $[min(L, \lfloor R/2\rfloor + 1) ,R]$ 中选一个最大合法集合。可以发现，映射后的集合天然满足“无倍数关系”，因此只需满足两两不互质即可。

设 $x = min(L, \lfloor R/2\rfloor + 1)$，$y = R$

如果 $y - x + 1$ 为偶数，考虑配对： $(x,x+1),(x+2,x+3),\dots,(y-1,y)$ ，由于相邻两个数一定互质，因此每对至多选一个数。当每对都取偶数时，可以达到上界

如果 $y - x + 1$ 为奇数，按照配对法会出现 $[奇,偶,\dots,奇]$ 的情况，可以证明取区间内所有偶数仍是最优的。因为相邻两个奇数一定互质，如果某一对取了奇数，必然导致相邻两对中至少一对不可选

答案为 $max(1,\lfloor y/2 \rfloor - \lfloor (x-1) / 2 \rfloor)$
