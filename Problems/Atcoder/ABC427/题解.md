# G（构造 + 数学变换 + 数据结构）

* 题意：你会按顺序收到一系列礼物，初始有$N$个礼物，第$i$个礼物有属性值$P_i$，你有心情值$X$以及两个属性$A$和$B$。当收到礼物$i$时，若$X \geq P_i$，则令$X = X + A$，否则令$X = X - B$。你需要处理$Q$次查询：
  * $op_1$：给定$P$，在礼物序列末尾新增一个属性值为$P$的礼物
  * $op_2$：给定$X$，回答初始心情值为$X$时，收完所有礼物后的心情值是多少
* 范围：$N \in [1,2\times 10^5]$，$A,B \in [1,10^9]$，$P \in [-10^9,10^9]$，$X \in [-10^{12},10^{12}]$，$Q \in [1,2\times 10^5]$
* 关键思考：
  * 本题为数据结构类题目，需要读请题意，选用合适的算法和数据结构维护题目信息，回答询问
  * 首先思考暴力做法，对于每个第二类查询，我们需要$O(N)$的时间来模拟，总时间复杂度为$O(NQ)$，超时
  * 观察题目性质，不难发现题目维护的是一个线性变换：
    * $X_N = f(X_0)=X_0 + pA - qB$
  * 难点就在于这个分段函数性质非常差，有加有减使得我们很难从中挖掘出良好的性质
  * 因此，我们尝试构造一个能实现相同映射，但性质更加良好的函数
  * 设当前有$N$个礼物，那么我们把$X$到达最终值的过程拆分成$N$步：
    * $X_0 \to X_1 \to X_2 \to ... \to X_N$，
      * 从$X_i$到$X_{i+1}$有两种可能：
        1. $X_{i+1} = X_i + A$
        2. $X_{i+1} = X_i - B$
    * 观察上述过程，我们能否做些适当的数学变换，使得这个变化过程具有单调性，例如“只增不减”呢？
    * 很简单，我们只需要让$X'_{i + 1} = X'_i + B$即可，记$Y_i = X'_i$
    * $Y_0 \to Y_1 \to Y_2 \to...\to Y_N$，
      * 从$Y_i\to Y_{i+1}$有两种可能：
        1. $Y_{i+1} = Y_i + A + B$
        2. $Y_{i+1} = Y_i$
  * 我们找到了一种线性变换：$Y_i = X_i + i\times B$，这使得我们得到了简洁的映射函数：
    * $Y_N = g(Y_0) = Y_0 + t(A + B)$
    * $X_N = Y_N - N\times B$
  * 此时我们就很容易思考
