# F（构造 + 贪心 + 分治 + 数学）

* 题意：给定整数$n$，你需要构造一个二元组序列$(y_1,l_1),\dots,(y_k,l_k)$来控制一个初始未知但满足$s \in [1,n]$的变量$s$。第$i$次操作时，若当前$s = y_i$则$s \leftarrow s + l_i$，否则$s$不变；该次操作的代价为$l_i$，且当$i > 1$且$y_i > y_{i-1}$时额外增加$1000$代价。请输出满足总代价不超过$10^6$且能保证操作结束后任意初始$s$均满足$s \geq n$的操作数量$k$及具体序列。
* 范围：$n = 250000$
* 关键思考：
  * 本题为判定与结构分析类题目，常用思考方式为：从小规模数据中探寻规律，从特殊到一般
  * 首先，我们很容易想到两种策略：
    1. 倒序操作，把$[1,n-1]$分别增加$n-1,n-2,\dots,1$，总代价为$\displaystyle\frac{n(n-1)}{2}$
    2. 正序操作，把$[1,n-1]$分别增加$1,1,\dots,1$，总代价为$1000 \times (n - 2)$
  * 然而，我们最终要保证代价 $ < 4n$，显然两种方案都不满足
  * 为了减少代价，我们有种很经典的优化思路：分治
  * 为了把$[1,n]$全部提升到$\ \geq n$，我们可以做如下归并分治：
    * $divide$：把$[1,n /2]$提升到 $n / 2$，$[n/2+1,n]$提升到 $n$
    * $merge$：把$n/2$提升到 $n$
  * 转化成递推方式来看这件事，我们实际上在做以下操作：
    * 把$[1,n]$中$\mod 2 = 1$的数$ + 1$
    * 把$[1,n]$中$ \mod 4 = 2$的数$ + 2$
    * $...$
    * 把$[1,n]$中$\mod 2^k = 2^{k-1}$的数$ + 2^{k-1}$
  * 利用倒序操作，我们可以只在“层间”转换时需要支付额外的$1000$代价，而每层的代价为$n$
    * 因此总的代价为$\log_2 n \times(n + 1000) > 4n$，仍然不符合要求
  * 关键问题在于，递归的层数过高，$\log_2n$大约为$18$，我们需要降低这个系数
  * 一种思路是把$n$变小，即对$n$进行分块，设块长为$B$，则代价约为：
    * $\displaystyle \log_2B \times(n + 1000) + 1000 \times \frac{n}{B}$
    * 然而，即使这样我们也最少需要$273$万代价（$B = 690$），完全不能通过
  * 我们必须从结构上进行优化，既然二叉树过高，我们能否将其改为多叉树呢？
  * 假设我们改为$m$叉树，则我们的操作就变成：
    * 把$[1,n]$中$\mod m^1 \ne m^0$的数提升到$m^1$
    * 把$[1,n]$中$\mod m^2 \ne m^1$的数提升到$m^2$
    * $\dots$
    * 把$[1,n]$中$\mod m^k \ne m^{k-1}$的数提升到$m^k$
  * 此时，每层要处理$m-1$个非$0$余数，如何把这些不同余数的数字提升到余数为$0$呢？
  * 还是经典的两个思路，要么是倒序把$[1,m-1]$分别增加$m-1,m-2,\dots,1$，要么就是正序把$[1,m-1]$分别增加$1,1,\dots,1$
    * 一种是$\displaystyle \frac{m(m-1)}{2} \times \frac{当前层节点个数}{m}$，一种是$当前层节点个数 + 1000 \times (m - 2)$，显然当每层节点过多时要采用后者，下文我们同意按照后者进行
  * 此时，总代价为：
    * $\displaystyle \log_m n(n + 1000m)$
