# E2

题意：构造一个长度为 $N$ 的数组 $b$（$0 \le b_i \le N$），使得对于每一个前缀 $b_1,\dots,b_i$，它的第 $(N-i+1)$ 个缺失的非负整数恰好是 $a_i$。求满足条件的数组 $b$ 的数量，对 $10^9 + 7$ 取模

数据范围：$N \in [1,10^5]$，$a_i \in [1,10^9]$

本题为计数类题目，常用思考方式为：暴力 $\to$ DP || 组合数学，常用优化手段为：前缀和、双指针、数据结构

*  首先思考这样一个问题：对于一个前缀区间求第 $k$ 小 $mex$ 的含义是什么？这意味着对于 $[0,a_i-1]$，恰好有 $k-1$ 个数没有在 $[1,i]$ 中出现，且 $a_i$ 一定不在 $[1,i]$ 中出现

* 反过来想，在 $[0,a_i-1]$ 中，恰好有 $a_i-k+1$ 个数在 $[1,i]$ 中出现

* 遇到求 $k$-MEX 类的集合膨胀问题，永远尝试去追踪**缺失集**

  令 $M_i = [0,n]\setminus S_i$ 为第 $i$ 步后的缺失元素集合。题目等价于：$a_i$ 是 $M_i$ 中的第 $n-i+1$ 小的元素

  随着 $i$ 的增大，$S_i$ 扩大，$M_i$ 缩小，区间内的缺失元素不可能变多。因此，序列 $a$ 必须是非严格单调递减的

* 考虑倒序 $dp$，为方便起见，我们设 $a_0 = N$，表示一个空集的第 $N+1$ 个缺失的非负整数是 $N$。

  * 当 $a_i = a_{i-1}$ 时，推导可得：$[0,a_i-1]$ 中恰好有一个数在 $[1,i-1]$ 中没出现，在 $[1,i]$ 中出现。因此 $b_{i}$ 只能填 $[0,a_i-1]$ 中，在 $[1,i]$ 中出现过，但在 $[1,i-1]$ 中没出现的数。

    那么，在状态 $i$ 时，$[0,a_i-1]$ 这个值域内，有多少个数是出现过的呢？

    根据推导，缺失的数有 $n - i$ 个，那么出现的数就有 $a_{i} - n+i$ 个，我们需要从中任选一个，并承诺该元素在 $[1,i-1]$ 中不再出现

  * 当 $a_i < a_{i-1}$ 时，条件为在 $[1,i]$ 中 $[0,a_i-1]$ 缺失 $n-i$ 个，在 $[1,i-1]$ 中 $[0,a_{i-1}-1]$ 缺失 $n-i+1$ 个

    关键点在于 $a_i \in [0,a_{i-1}-1]$，而 $a_i$ 在 $[1,i-1] \sub [1,i]$ 中是一定不会出现的，因此所谓的"在 $[1,i-1]$ 中 $[0,a_{i-1}-1]$ 缺失 $n-i+1$ 个"，多缺出来的这一个必然正好是 $a_i$

    这样我们就知道了：对于当前 $[1,i]$ 中 $[0,a_i-1]$ 缺失的这 $n-i$ 个数，在 $[1,i-1]$ 的这个值域内仍是缺失的，因此 $b_{i}$ 一定不能取这 $n-i$ 个数，则有 $n - (n - i) = i$ 种方案

* 从缺失集角度思考，会对本题产生更为深刻的理解：

  * 我们考虑倒序维护**前缀缺失集R**，想象这个集合是一个有序数组，初始时指针指向数组开头

  * 当 $a_i = a_{i-1}$ 时，指针向后滑动一格，元素值却没变，这说明什么？说明我们在 $i \to i-1$ 时在指针前面添加了一个元素。由于是有序的数组，这要求添加的元素必须 $ < a_i$，而指针前面已经有 $n-i$ 个数，因此可添加的元素共有 $a_i - n + i$ 个

  * 当 $a_i < a_{i-1}$ 时，指针向后滑动一格，元素值变大了，这说明什么？说明当前的 $b_i$ 一定不能是指针前面的 $n - i$ 个数和当前的 $a_i$，共 $n - i + 1$ 个不可选的数。 

    为什么不要求 $b_i$ 不能是 $ < a_i$ 的新元素呢？

    既然 $a_i$ 在 $R_i$ 中排在第 $n-i+1$ 位，要让更大的 $a_{i-1}$ 在 $R_{i-1}$ 中排在第 $n-i+2$ 位，那么 $R_{i-1}$ 的前 $n-i+1$ 个元素必须和 $R_i$ 一模一样。

    如果要添加新元素，也就是在 $[1,i-1]$ 中不出现，在 $[1,i]$ 中出现，就需要这个元素 $\notin R_i$ 并且 $\in R_{i-1}$，这在这个元素 $ < a_i$ 时是无解的

    综上，可以选择 $n + 1 - (n - i + 1) = i$ 个数
