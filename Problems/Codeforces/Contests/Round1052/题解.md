# D1（构造 + 贪心）

* 题意：给定两个整数$l$和$r$，令$n = r - l + 1$，创建一个长度为$n$的数组$a,b$，初始时$a=b=[l,l+1,\dots,r]$。你可以任意重排数组$a$，目标是最大化$\displaystyle \sum_{i = 1}^{n} \left( a_i | b_i \right)$。在这个版本中保证$l=0$。
* 范围：$0 = l \leq r < 2 \times 10^5$
* 关键思考：
  * 本题为决策类题目，常用思考方式为：暴力$\to$DP$||$**贪心**$||$网络流，常用优化手段为：二分、前缀和、双指针、数据结构。
  * 首先思考题目性质，可以建模为**二分图最大权完美匹配**问题，直接网络流显然超时，因此我们需要往贪心上思考
  * 由恒等式$a|b=a+b-a\&b$可知，原问题等价于最小化$\displaystyle \sum_{i=1}^{n} \left( a_i\&b_i \right)$。于是我们想，能否有一种匹配方式使得所有的$a_i \& b_i = 0$呢？因为这是理论最小值。如果不能达到，我们希望位交集部分尽可能在较低位上，这样与运算后得到的值就尽可能地小。
  * 当$r$形如$2^i - 1$时是简单的，此时只需要把 $j$ 和 $2^i-1-j$ 进行匹配即可
  * 当$r$无法表示为$2^i-1$时，不能再像上面一样简单构造了，但我们仍希望利用它做些文章：
    * 取$i = max\{i|2^i-1\leq r\}$，则$[0,2^i-1]$可以实现最优匹配，但这种策略会导致$[2^i,r]$中的高位$1$被白白浪费掉，直觉上就是不优的。
    * 进一步思考，$[0,r-2^i]$和$[2^i,r]$仅有最高位不同。因此原来是$[0,r-2^i]$与$[2^i-1-(r-2^i),2^i-1]$进行匹配，我们将其更换为$[2^i,r]$与后者进行匹配，得到的结果必然更优，因为这样没有损失低位 并且 保留了高位的贡献
      * ![image-20250924015446764](C:\Users\31435\AppData\Roaming\Typora\typora-user-images\image-20250924015446764.png)
      * 接下来就变成$[0,2^i-1-(r-2^i)-1]$进行匹配这个规模更小的子问题，递归求解即可
  * 能够递归的关键在于$[2^i,r]$的长度永远小于等于$[0,2^i-1]$，这样每次都是从$[0,r]$转化到$[0,r']$，而每次转化都是无损的，因此最终得到的答案必然最优。

# D2（构造 + 贪心）

* 题意：同$D1$
* 范围：$0 \leq l \leq r < 2^{30}$，保证$r - l + 1 \leq 2 \times 10^5$
* 关键思考：
  * 与$D1$不同的是，在本题中$[2^i, r]$的长度不一定小于等于$[l,2^i-1]$的长度了，如下图所示：
    * ![image-20250925113850540](C:\Users\31435\AppData\Roaming\Typora\typora-user-images\image-20250925113850540.png)
  * 对于上面这种例子，我们会发现，无论如何进行匹配，都会至少浪费$2$个最高位$1$
  * 既然如此，我们就希望找到一种新策略，满足最高位浪费的数量最少，且其余位无损匹配
    * ![image-20250925114607852](C:\Users\31435\AppData\Roaming\Typora\typora-user-images\image-20250925114607852.png)
  * 如上图所示，令$len = min(2^i - l, r - 2^i +1)$，如果$2^i-l < r - 2^i + 1$，我们就将$[l,l+len-1]$进行匹配，并把问题递归到$[l+len,r]$；如果$2^i-l>r-2^i+1$，我们就将$[r-len+1,r]$进行匹配，并把问题递归到$[l,r-len]$
  * 每次递归都保证了：不损失更低位的情况下，当前位损失最小。这样结果必然是最优的。
