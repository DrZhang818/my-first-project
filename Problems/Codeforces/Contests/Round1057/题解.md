# A（贪心）

* 题意：有$N$棵苹果树围成一个圈，每棵树上都结有一个苹果，第$i$棵树上的苹果美丽值是$b_i$。你从第$1$棵树开始，每到一棵树，若树上还有苹果，你可以选择吃掉苹果，或者跳过它。接着，你会走到下一棵树：从第$i$棵树走到第$i+1$棵树$(1 \leq i \leq n - 1)$，从第$n$棵树走到第$1$棵树，你会一直这样循环走下去。你必须保证吃掉的每个苹果的美丽值严格大于上一次吃掉的苹果美丽值，请你求出最多能吃掉几个苹果
* 范围：$N \in [1,100]$，$b_i \in [1,N]$
* 关键思考：
  * 本题为决策类题目，常用思考方式为：暴力$\to$DP||贪心||网络流，常用优化手段为：二分、前缀和、双指针、数据结构
  * 首先观察题目性质，由于我们是无限移动的，因此我们可以构造以下方案：
    * 每轮移动只吃掉所有**能吃的**苹果中的最小值
  * 不难发现，答案就是数组去重后的大小



# B（构造）

* 题意：给定三个非负整数$x,y,z$，判断是否存在三个整数$a,b,c$满足：
  * $a \ \& \ b = x$
  * $b \ \& \  c = y$
  * $a \ \& \ c = z$
* 范围：$x,y,z \in [0, 10^9]$
* 关键思考：
  * 本题为构造类题目，常用思考方式为：从小规模数据中探寻规律，从特殊到一般
  * 首先观察题目性质，容易想到一个必要条件：
    * 设$V=a\ \&\ b\ \&\ c$，则有$(x \ \& \ y = V)∧(x\ \& \ z = V)∧(y\ \&\ z =V)$
    * 即$(x \ \& \ y) = (x\ \&\ z) ∧ (x\ \&\ y) = (y\ \&\ z)$
  * 考虑按位构造：
    * 对于第$i$位：
    * 若$a,b,c$中有$\ \leq 1$个在该位为$1$，则$x,y,z$在该位都是$0$
    * 若有$2$个在该位为$1$，则$x,y,z$中有且仅有$1$个在该位是$1$
    * 若$3$个在该位都是$1$，则$x,y,z$在该位也必须都是$1$
    * 一种符合条件的构造为：$a = x\ |\ z,\ b = \ x\ |\ y,\ c =\ y\ |\ z$
  * 因此，有解的充要条件是对于任意一位，$x,y,z$不能恰好有$2$个在该位为$1$
  * 事实上，$(x \ \& \ y) = (x\ \&\ z) ∧ (x\ \&\ y) = (y\ \&\ z)$也是充要条件，这个式子正是表达了$x,y,z$不能恰有$2$个在某位为$1$
