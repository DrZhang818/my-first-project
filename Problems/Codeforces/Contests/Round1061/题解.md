# D（构造）

* 题意：这是一个交互题
  * 有一个长度为$n$的隐藏排列$p$，你最多进行以下交互：
    * $query$：选择两个整数$i$和$x$，满足$1\leq i\leq n - 1$和$1\leq x \leq10^9$。如果$p_i \& x=0$，交互器会返回$0$，否则返回$1$
  * 你需要在最多$2n$次交互内，确定排列中最后一个元素$p_n$的值
  * 交互器是非自适应的
* 范围：$n \in [2,2\times10^4]$
* 关键思考：
  * 本题为构造类题目，常用思考方式为：从小规模数据中探寻规律，从特殊到一般
  * 首先观察题目性质：由于涉及位运算，因此我们就应该逐位进行思考。
  * 从简单情况出发：如何确定最低位是$0$还是$1$呢？显然可以让$p_1\to p_{n-1}$与$1$做与运算，然后数一下返回$1$的个数是否等于$1\to n$与$1$做与运算返回$1$的个数。如果相等，说明$p_n$的最低位为$0$，否则说明最低位为$1$

# E（博弈论 + 贪心 + 枚举）

* 题意：定义一个长度为$m$的数组$b$的权值为$\displaystyle \max_{1 \le i < j \le m}\left( b_j - b_i \right)$。
  * 现有一个长度为$n$的数组$a$，所有数字都是未锁定状态。$Alice$和$Bob$轮流操作，$Alice$先手：
    * $Alice$的回合：从数组$a$中移除一个未锁定元素
    * $Bob$的回合：从数组$a$中锁定一个未锁定元素
  * 当数组$a$中所有元素都被锁定或移除，游戏结束。可以证明游戏共进行$n$轮，恰好有$\lfloor \frac{n}{2} \rfloor$个元素被锁定
  * $Alice$想让最终锁定元素组成的数组的权值尽可能小，$Bob$则希望它尽可能大。假设二人都以最优策略进行，求最终数组的权值
* 范围：$n \in [4,10^5]$，$a_i \in [1,10^9]$
* 关键思考：
  * 本题为决策类题目，常用思考方式为：暴力$\to$DP||贪心||网络流，常用优化手段为：二分、前缀和、双指针、数据结构
  * 首先分析题目性质：由于数组权值定义为所有有序数对的最大极差，因此$Alice$的条件是个全局约束，而$Bob$的条件是个局部约束。简单来说，对于任意整数$x$，如果$Alice$想让数组权值$\leq x$，就需要确保所有满足$a_j - a_i > x$的有序数对都被删除。而如果$Bob$想让数组权值$ \geq x$，就只需要保留住任意一个满足$a_j - a_i \geq x$的数对
  * 在分析时，往往全局约束会带来良好的性质，我们研究一下$Alice$的操作性质。下面的分析用到“二分答案法“的思想，当直接寻找最优解很困难的时候，如果我们发现答案具有单调性，就可以尝试用**二分/枚举答案 + $check$合法性**这种方式逐步找到最优解
  * 钦定答案$\leq x$，那么判断条件就是：$Alice$能否通过移除一个数，使得剩下的局面交给$Bob$后，无论$Bob$怎么操作，$Alice$都有办法使最终的权值$\leq x$
  * 看似这个问题还是要递归的求解下去，但是我们仔细思考，利用$Bob$的局部约束，我们就会发现一种更简单的判别方法
  * 轮到$Bob$后，他的目标就变成想办法使数组的权值$ > x$，也就是留住两个$i,j$，满足$a_j - a_i > x$。因此，只要$Bob$选了$i,j$中的一个，$Alice$就必须移除另一个。
    * 于是我们立刻意识到，如果对于$i$，有至少两个不同的$j$满足$a_j - a_i > x$或$a_i - a_j > x$，那么我们留住$i$之后，由于$Alice$最多删掉其中一个，那么紧接着再次轮到我们的时候一定还有至少一个合法的$j$可以选择，那么就必然导致数组权值$ > x$。
    * 相应的，如果对于所有的$i$，最多只有一个$j$满足$|a_j - a_i| > x$，那么$Alice$就必然可以破坏所有数对，使得数组权值$\leq x$
  * 对于$|a_i - a_j| > x$，我们建一条无向边$(i,j)$，那么$Alice$的判断条件就变成：能否删除图上的一个点，使得其余点的最大度数$\leq 1$，最终答案就是最大的不满足该条件的$x$
  * 我们考虑从大到小依次加边，并检查当前图是否符合$Alice$的要求，暴力加边 + 删点的复杂度为$O(n^4)$，超时
  * 由于每个点的判断逻辑是：删除某个点后，检查$deg$是否$\geq 2$，因此只需要保留最多$3$条边权最大的边即可。这样边数就从$O(n^2)$降为了$O(n)$
  * 然而这样的复杂度还是$O(n^2)$的，如何做进一步优化呢？
  * 问题在于，每次加一条边就做一次$check$太慢了，我们可以更换枚举对象：
    * 枚举删除的点，然后按照边权从大到小一次性加入所有**在删除该点后**允许加入的边。
    * 最终，无法加入的边中的边权最大值就是答案

# F1（贪心）

* 题意：给定一个长度为$n$的排列$p$，你可以进行任意次以下操作：
  * $op$：选择三个不同下标$i,j,k(1 \leq i < j < k \leq n)$，满足$p_i = max(p_j,p_k) + 1且p_i = min(p_j,p_k) + 2$，然后将$p_i$减$2$，$p_j和p_k$加$1$。
  * 可以证明操作后的$p$仍然是一个排列
  * 求通过操作能够得到的最小字典序排列
* 范围：$n \in [3,2000]$
* 关键思考：
  * 本题为决策类题目，常用思考方式为：暴力$\to$DP||贪心||网络流，常用优化手段为：二分、前缀和、双指针、数据结构
  * 首先分析题目性质：哪些三元组$(i,j,k)$是可交换的呢？
    * 简单手玩一下就会发现，只有三元组的值$(p_i,p_j,p_k)$形如$(x + 2, x, x + 1)$或者$(x + 2, x + 1, x)$时才可以交换
  * 进一步地，我们研究一下交换模式：
    * 对于$(x + 2, x, x + 1)$，交换后变为$(x, x + 1, x + 2)$
    * 对于$(x + 2, x + 1, x)$，交换后变为$(x, x + 2, x + 1)$
  * 可以发现，只要能发生交换，无论哪种模式交换后都是更优的，那这是否意味着可以随意交换直至无法进行呢？
  * 问题就在这里，我们的交换操作可能有次序要求。可能某种交换进行后会导致另一个交换无法进行，从而答案变劣
  * 不难发现，交换$(x,x + 1, x+2)$只会影响到$x - 2, x - 1, x, x + 1, x + 2$这些数
    * 对于$x - 2$来说，想要把它移到前面就需要$q_x < q_{x-1}且q_x < q_{x-2}$，而两种交换模式都导致$q_x$变小，因此是更优的
    * 对于$x - 1$来说，需要$q_{x + 1} < q_x且q_{x + 1} < q_{x - 1}$，第二种交换模式会导致$q_{x + 1} > q_x$，变劣
    * 对于$x + 1$来说，需要$q_{x + 3} < q_{x + 2}且q_{x + 3} < q_{x + 1}$，两种操作都会导致更优
      * 这里有个逻辑陷阱，第一种交换模式看似会导致$q_{x-1} < q_{x-3}$，但由于我们的目标是最小化字典序，这样反而是优的
    * 对于$x + 2$来说，需要$q_{x + 4} < q_{x + 3}且q_{x + 4} < q_{x + 2}$，两种模式都导致$q_{x + 2}$增大，更优
  * 因此，问题就非常清晰了，只有使用第二种交换模式交换$x$时会影响$x-1$的交换
  * 那么我们就有了个非常自然的贪心：按照值域从小到大进行交换
  * 由于交换是有先后次序的，可能必须交换了更大的数才能再交换当前的数，因此我们需要做类似冒泡排序一样的$O(n^2)$枚举
  * 最终就可以在$O(n^2)$时间内解决本题
