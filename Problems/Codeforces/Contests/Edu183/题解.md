# A（数论）

* 题意：给定一个整数$x$，求最少把$x$加上多少，才能使$x$成为$3$的倍数
* 范围：$x \in [1,100]$
* 关键思考：
  * 本题为决策类题目，常用思考方式为：暴力$\to$DP||贪心||网络流，常用优化手段为：二分、前缀和、双指针、数据结构
  * 输出$(3 - x \ \% \ 3) \ \% \ 3$即可



# B（贪心 + 博弈）

* 题意：$N$张牌从小到大排序，$1$号牌在最上面，$N$号牌在最下面。接下来有$k$次操作：
  * $0$：移除最上面的一张牌
  * $1$：移除最下面的一张牌
  * $2$：移除最上面或最下面的一张牌（任选其一）
  * 你的任务是判断每张牌的命运：一定在牌堆中/一定不在牌堆中/都有可能
* 范围：$N \in [1,2 \times 10^5]$，$k \in [1,N]$
* 关键思考：
  * 本题为决策类题目，常用思考方式为：暴力$\to$DP||贪心||网络流，常用优化手段为：二分、前缀和、双指针、数据结构
  * 首先观察题目性质，我们发现操作顺序对结果是没有任何影响的，因此我们先执行所有的操作$0$和操作$1$
  * 执行过后，我们记剩下的字符串长度为$m$，操作$2$的次数为$k$，则有以下情况：
    * 若$m = k$，显然无论如何操作都会被删光
    * 若$m < k$，对于任意一个字符，我们都有办法将其保留，因此只需判断是**一定被保留**还是**可能被保留**：
      * 对于前$k$个字符和后$k$个字符，我们都有办法将其删除，因此这些字符是**可能被保留**
      * 如果一个字符既不是前$k$个也不是后$k$个，那么一定无法删除它，所以这些字符是**一定被保留**



# C（枚举 + 前缀和）

[CF2145C](https://codeforces.com/contest/2145/problem/C)

* 题意：给定一个长度为$N$的字符串，只包含$'a','b'$两种字符，你可以从字符串的任意位置开始删除一个任意长度的子串，使得剩下的字符串中的$'a','b'$数量相同。求出最小需要删除长度为多少的子串。如果必须删除整个字符串，输出$-1$
* 范围：$N \in [2,2 \times 10^5]$
* 关键思考：
  * 本题为决策类题目，常用思考方式为：暴力$\to$DP||贪心||网络流，常用优化手段为：二分、前缀和、双指针、数据结构
  * 首先观察题目性质，让两种字符数量相同，这是个很经典的问题，我们可以把`a`看作$1$，把`b`看作$-1$，这样就把`ab`数量相同转化成整个数组求和后值为$0$
  * 那么原问题就转化成：从数组中删除一个子数组，使得总和为$0$，这是个非常基础的前缀和问题。



# D（构造 + DP + 组合数学）

[CF2145D](https://codeforces.com/contest/2145/problem/D)

* 题意：定义一个排列$p$的权值为包含至少一个逆序对的子数组数量。给定两个整数$N,k$，构造一个长度为$N$的排列，使得它的权值恰好等于$k$。若不存在满足条件的排列，输出$0$

* 范围：$N \in [2,30]$，$k \in [0, \frac{N(N-1)}{2}]$，$T \in [1,500]$

* 关键思考：

  * 本题为构造类题目，常用思考方式为：从小规模数据中探寻规律，从特殊到一般

  * 首先观察题目性质，题目要求的子数组是**至少包含一个**逆序对，这种条件强烈暗示我们从反面进行思考，即合法子数组数量 = 总数 - 不合法子数组数量。而不合法子数组等价于**不包含任何**逆序对，即子数组单调递增。

  * 于是，问题就转化为构造一个排列，使得不合法子数组数量恰好为$\frac{N(N+1)}{2} - k$

  * 对于一个长度为$m$的单调递增数组，能够贡献$\frac{m(m+1)}{2}$个不合法子数组。而一个排列$p$可以划分成若干段单调递增的子数组，因此问题本质上是把$N$划分成$\{ a_1,a_2,...,a_n \}$，满足$\sum a_i = N$且$\sum \frac{a_i(a_i+1)}{2} = \frac{N(N+1)}{2} - k$

  * 显然这是一个完全背包模板题，由于只需要判断能否组成，我们可以用$bitset$进行优化，具体过程不做展开

  * 接下来的问题是如何构造方案，这里涉及到一些技巧性：

    * 设当前状态为$dp[i][j]$，表示还剩$i$个数没有填，还需要$j$个不合法子数组
    * 枚举下一步填的数量$k$，若发现$dp[i-k][j-\frac{k(k+1)}{2}]=1$，说明$(i,j)\to (i-k,j-\frac{k(k+1)}{2})$是有效的转移。此时我们应该用哪些数来构成长度为$k$的单调递增数组呢？
      * 由于我们要保证单调递增的长度**恰好**为$k$，也就是要确保下一次填的数一定要**递减**下去，因此我们可以把当前剩余的数中的前$k$大填进来，这样下一次无论怎么填，一定会终止单调递增，确保递增长度恰好为$k$。 
    * 因为是完全背包，如果当前能用$k$进行转移，下一次仍有可能是用$k$转移，因此写$for$循环时注意让$k--$

    



# E（线段树二分）

[CF2145E](https://codeforces.com/contest/2145/problem/E)

* 题意：给定两个值$X$和$Y$，有$N$个人，每人有两个属性，用两个长度为$N$的数组$a,b$表示，第$i$个人的权值$w_i$为$max(a_i-X,0) + max(b_i-Y,0)$。局面得分的计算方式为：初始化$p=0$，集合$S=\{1,2,\dots,N\}$，若存在$i\in S$满足$w_i\leq p$，则令$p=p+1,S=S / \{i\}$，直到不存在满足条件的$i$为止，最终得到的$p$即为得分。
  * 你需要处理$m$次询问：每次询问给定$k,na,nb$，将$a_k,b_k$分别更改为$na,nb$，回答更改后的局面得分。
* 范围：$X,Y \in [1,10^6]$，$N \in [1, 5\times 10^5]$，$a_i,b_i \in [1,10^6]$，$m \in [1,3 \times 10^5]$
* 关键思考：
  * 本题为数据结构类题目，需要认真读清题意，选用合适的算法和数据结构维护题目信息，回答询问。
  * 首先考虑单次询问该怎么做：
    * 我们把$w_i$全部计算出来，并按照升序排序。为了方便，让数组下标从$0$开始计数。从前向后遍历，第一个满足$w_i>i$的索引$i$就是答案。$w_i>i$这个条件，等价于数组第$i+1$小大于$i$。
  * 对于多组询问，我们显然不能每次都排序 + 遍历，必须找到更高效的维护方法。
  * 思考以下问题：存在修改的情况下，如何快速判断数组第$k+1$小是否大于$k$？
    * 这是个经典问题，可以用值域树状数组或权值线段树维护，有两种实现方式：
    * 单点修改 + 区间查询：$tr[k]:=$ 值等于$k$的数量，查询$tr[0,k]$的总和$sum$是否$\leq k$。当$sum \leq k$时，表示只有$k$个数$\leq k$，因此满足第$k+1$小$>k$，否则不满足。
    * 区间修改 + 单点查询：$tr[k]:=$ 值小于等于$k$的数量，查询$tr[k]$是否$\leq k$，原理同上。
    * 由于第二种实现方式只需要维护单点值，更为简单高效，因此我们采用第二种实现。
  * 问题进一步升级，我们不仅要判断，还要找到第一个满足$w_i > i$的索引，即第一个满足$tr[i] \leq i$的索引$i$
  * 这里使用常用的归一化$trick$，我们令$tr[i] = tr[i] - i$，这样就与$i$无关了，我们只需要查询第一个满足$tr[i] \leq 0$的索引
  * 能否使用二分的方式来找到这样一个特殊点位呢？这就需要我们挖掘序列的特点
    * 设$i$是第一个满足$tr[i] \leq 0$的位置，此时$tr[0:i-1] > 0, tr[i] \leq 0, tr[i+1:N]$未知，用什么作为分界点可以区分开$[0,i-1]$与$[i,N]$？
    * 不难发现，可以用**最小值是否大于0**来作为分界点
  * 综上，我们需要一个数据结构支持**区间加**，**单点查值**，**区间查最小值**，显然可以用线段树来维护
  * 通过在线段树上二分，我们就能快速找到待求的索引了
