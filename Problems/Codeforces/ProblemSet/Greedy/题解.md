# LC1553 贪心 + DP

[LC1553](https://leetcode.cn/problems/minimum-number-of-days-to-eat-n-oranges/description/)

* 题意：给定一个整数$x$，你可以进行以下操作：

  * $op1:\ $令$x = x - 1$
  * $op2:\ $若$x$是$2$的倍数，令$x = x / 2$
  * $op3:\ $若$x$是$3$的倍数，令$x = x / 3$

  求最少需要几次操作使得$x$变为$0$

* 范围：$x \in [1,2 \times 10^9]$

* 关键思考：

  * 本题为决策类题目，常用思考方式为：暴力$\to$DP||贪心||网络流，常用优化手段为：二分、前缀和、双指针、数据结构

  * 首先观察题目性质，我们显然有个$O(n)$的$dp$做法：

    * 设$dp[i]:=$ 将$i$变为$0$的最小操作次数，则有如下转移：

      $dp[i] = dp[i - 1] + 1$

      若$i \  mod \  2 = 0$，$dp[i] = min(dp[i],dp[i / 2] + 1)$

      若$i\ mod\ 3 = 0$，$dp[i] = min(dp[i],dp[i/3]+1)$

  * 但在本题中$x$范围达到$2 \times 10^9$，上述做法会超时，需要优化

  * 瓶颈在于转移方程中涉及$dp[i-1]$，这导致我们必须完整知道$0\to i-1$中的每个$dp$值才能递推到$dp[i]$

  * 思考操作性质，不难发现操作$1$的效率总是不如操作$2$和操作$3$高，因此能否有一种贪心策略将转移方程中的$dp[i-1]$项去掉呢？

  * 对任意操作序列，我们都可以对其进行划分成若干个"减1除2"段，"减1除3"段，以及最后归零的"减1"段

  * 下面分别研究三段的性质：
  
    * **减1除2段**：
  
      设当前数为$x$，进行了$t$次减$1$操作以及$1$次除以$2$操作，则：
  
      $x = \frac{x - t}{2}$，显然有$t = x(mod2)$
  
      我们可以发现以下性质：
  
      * 当$x\ mod\ 2 = 0$时，$t > 0$是不优的：
        * 我们可以先进行$1$次除以$2$操作，再进行$\frac{t}{2}$次减$1$操作，同样可以得到$\frac{x-t}{2}$，且操作次数$ < t$
      * 当$x\ mod\ 2 = 1$时，$t > 1$是不优的：
        * 我们可以先进行$1$次减$1$操作和$1$次除以$2$操作，再进行$\frac{t-1}{2}$次减$1$操作，同样可以得到$\frac{x-t}{2}$，且操作次数$<t$
  
      因此，这种情况下$t \leq 1$
  
    * **减1除3段**：
    
      同理，我们可以证明这种情况下$t \leq 2$
      
    * **减1段**
    
      同理，我们可以证明这种情况下$t \leq 1$
    
  * 我们可以把**减1**操作看成是**除以2、除以3、归零**的前置操作，这样就得到了以下转移方程：
    $$
    \begin{flalign*}
    dp[i] = 
    \begin{cases}
    i,\ &i \leq 1\\
    min\left(i\ mod\ 2 + dp[i / 2] + 1, i\ mod\ 3 + dp[i / 3] + 1 \right), &i > 1
    \end{cases}
    \end{flalign*}
    $$
  
  * 
  
  * 时间复杂度为$O(log^2n)$
