
10.3循环群与置换群

循环群和置换群是群论中的两类重要的群
(一)循环群
定义: 若存在 a∈G 使得G = <a>, 则称G为循环群, 称a为G的生成元
    简单来说, 一个循环群就是可以由一个元素"独自生成"所有成员的群
    a是生成元 <==> G中所有元素可以写成a^k的形式

循环群G = <a>根据生成元a的阶数可以分成两类: 
    (1)n阶循环群 
        若a是n阶元, 则 G = {a^0, a^1, a^2, ..., a^{n-1}}, 这时 |G| = n
        举例: 
            模6整数加群 <Z_6, ⊕>, 它是6阶循环群, 生成元为 1 和 5
    (2)无限循环群
        若a是无限阶元, 则G = {a^0, a^{+-1}, a^{+-2}, ...}
        举例:
            整数加群 <Z,+>, 它的生成元是 1 和 -1 

如何求解循环群G = <a>的所有生成元?
定理10.11:
    设 G = <a>是循环群
    (1)若G是无限循环群, 则G只有两个生成元, 即 a 和 a^{-1}
    (2)若G是n阶循环群, 则G含有ϕ(n)个生成元. 对于任何小于等于n且与n互素的自然数r, a^r是
       G的生成元

    证明(1):
        显然<a^{-1}>⊆G, 为证明G ⊆ <a^{-1}>, 只需证明对任意的a^k∈G, a^k都可以表成a^{-1}的幂
            a^k = (a^{-1})^{-k}
        从而得到G ⊆ <a^{-1}>, a^{-1}是G的生成元
        下面证明 G 只含有这两个生成元
        假设b也是G的生成元, 则G = <b>, 由a ∈ G可知, 存在整数t, 使得a = b^t
        又由b ∈ G = <a>可知, 存在整数m, 使得b = a^m
        那么a = a^{mt}, 由消去律可得, a^{mt-1} = e
        因为G为无限群, 必有mt - 1 = 0, 从而m = t = 1或m = t = -1
        即b = a 或 b = a^{-1}

    idea:
        如何证明一个元素a是生成元?
        只需证明所有元素都能写成a^k的形式

        如何证明唯一性?
        经典的策略是, 假设存在另一个(任意的)生成元b, 通过逻辑推导证明b只能是a或a^{-1}

        无限循环群的性质: a^k = e <==> k = 0
    
    证明(2):
        当n = 1时显然成立, 因此只需证明: 对任何正整数r∈[1,n-1], a^r是G的生成元当且仅当
        n与r互素
        充分性: 
            设r与n互素, 且r < n, 那么存在整数u,v使得 ur + vn = 1
            因此a = a^{ur + vn} = (a^r)^u * (a^n)^r = (a^r)^u
            这就推出任意a^k∈G, a^k = (a^r)^{uk} ∈ <a^r>, 即 G ⊆ <a^r>
            另一方面, 显然有<a^r> ⊆ G, 所以a^r是G的生成元
        必要性:
            设a^r是G的生成元, 则|a^r| = n. 令gcd(r,n) = d, 则存在正整数t使得r = dt
            因此有(a^r)^{n/d} = (a^{dt})^{n/d} = (a^n)^t = e
            因此|a^r|是n/d的因子, 即n整除n/d. 从而证明了d = 1, 则n与r互素

    idea:
        如何证明a^r是生成元?
        最直接的方法是证明a ∈ <a^r>, 如果a能被a^r生成, 那么整个群就能被a^r生成

        如何利用互素条件?
        根据裴蜀定理, gcd(r,n) = 1 <==> ur + vn = 1存在整数解

        生成元的性质
        生成元的阶数与群的阶数相同, 因此如果a^r是生成元, 那么(a^r)^n = e
        任何比n小的正整数x, 都无法满足(a^r)^x = e
        我们正是利用这一点, 令x = n / gcd(r,n), 只要gcd(r,n)不为1, 就会产生矛盾
        因此gcd(r,n)必然等于1

如何求循环群 G = <a> 的所有子群?
定理10.12:
    (1)设 G = <a> 是循环群, 则 G 的子群仍是循环群
    (2)若 G = <a> 是无限循环群, 则 G 的子群除 {e} 外都是无限循环群
    (3)若 G = <a> 是n阶循环群, 则对n的每个正因子d, G 恰有一个d阶子群

    证明(1):
        设 H 是 G = <a> 的子群, 若 H = {e}, 显然 H 是循环群; 否则取 H 中的最小正方
        幂元 a^m, 下面证明 a^m 是 H 的生成元
            显然<a^m> ⊆ G. 为证明 H ⊆ <a^m>, 只需证明 H 中的任何元素都可以表示成a^m的
        整数次幂.任取a^l ∈ H, 由带余除法, 存在整数q,r, 使得l = qm + r, 其中r∈[0,m-1]
        因此有a^r = a^{l-qm} = a^l * (a^m)^{-q}
        由a^l,a^m ∈ H 且 H 是 G的子群可知 a^r ∈ H, 因为 a^m 是H中最小正方幂元, 必有r=0
        这就推出 a^l = (a^m)^q ∈ <a^m>

    idea:
        "最小元素"原理
        回想G = <a>的所有生成元特征, 它们都满足a^r = (a^1)^r, 其中a^1就是G中的最小正方
        幂元, 所有生成元的幂次都是这个最小幂次的正整数倍
        于是我们自然地选取 H 中的最小正方幂元a^m, 相当于是生成元的base case

        带余除法
        我们要证明a^l可以用(a^m)^k表示
        等价于 l = km, 为了寻找k, 我们想到带余除法, 将l表示为qm + r, 再证明r = 0

    证明(2):
        设G = <a>是无限循环群, H 是 G 的子群. 若 H ≠ {e}, 则根据上面的证明可知 H = <a^m>
        其a^m是 H 的最小正方幂元. 假若|H| = t, 则|a^m| = t, 从而得到a^{mt} = e
        由于m > 0且t > 0, 故mt > 0, 这与 a 为无限阶元矛盾

    idea:
        本证明与定理10.11(1)的idea类似, 都利用了无限循环群的性质
        无限循环群的性质: 无限循环群的生成元是无限阶元
            a^k = e <==> k = 0
        简单来说, 由于a是无限阶元, 因此 a^m (m ≠ 0) 必然也是无限阶元

    证明(3):
        根据Lagrange定理, G 的每个子群的阶都是 n 的因子
        下面证明对于 n 的每个正因子 d 都存在一个 d 阶子群
        易见<a^{n/d}>是 G 的 d 阶子群. 假设H1 = <a^m>也是 G 的 d 阶子群
        则由(a^m)^d = e可知, n 整除 md, 即 n/d 整除 m. 令 m = (n/d)*l, l是整数
        则有a^m = (a^(n/d))^l ∈ H, 这就推出H1 ⊆ H, 又|H1| = |H| = d, 得H1 = H

    idea:
        构造性证明 or 存在性证明 
        Lagrange定理保证了阶数为d的群是可能存在的, 为证明其存在性, 可以采取构造性证明
        直接构造出一个合法的d阶子群, 从而完成证明
        构造性证明不仅完成了存在性证明的工作, 还额外提供了寻找这个子群的方式

        循环群元素阶公式
        在一个n阶循环群中, 元素a^k的阶是n / gcd(n, k)
        因此一个d阶循环群的生成元a^k要满足d = n / gcd(n, k), 从而k = n / d

        如何证明唯一性?
        先假设存在不同的d阶子群, 再通过逻辑推导这个子群与<a^{n/d}>是相同的

(二)置换群
n元置换的定义:
    设S = {1,2,...,n}, S 上的任何双射函数σ: S -> S 成为 S 上的n元置换.
    一般将n元置换记作:
        σ = (1    2    ... n   )
            (σ(1) σ(2) ... σ(n))

    idea: 
        置换是对一个有限集合中的元素进行重新排列的操作

置换的乘法:
    设σ,τ是n元置换, σ和τ的复合σ ° τ也是n元置换, 称作σ与τ的乘积, 记作στ

k阶轮换 / 对换:
    设σ是 S = {1,2,..,n}上的 n 元置换. 若
        σ(i_1) = i_2, σ(i_2) = i_3, ..., σ(i_{k-1}) = i_k, σ(i_k) = i_1
    且保持 S 中的其他元素不变, 则称 σ 为 S 上的 k 阶轮换, 记作(i_1,i_2,...,i_k)
    若k = 2, 则成 σ 为 S 上的对换

轮换表示式:
    设 S = {1,2,...,n}, 对于任何 S 上的 n 元置换 σ 一定存在着一个有限序列
    i_1,i_2,...,i_k, k ≥ 1, 使得
    σ(i_1) = i_2, σ(i_2) = i_3, ..., σ(i_{k-1}) = i_k, σ(i_k) = i_1 
    令σ_1 = (i_1,i_2,...,i_k). 它是从σ中分解出来的第一个轮换.
    根据函数的复合定义可以将 σ 写作 σ_1σ', 其中σ'作用与S - {i_1,i_2,...,i_k}上的
    元素, 经过有限步以后, 必得到 σ 的轮换分解式 σ = σ_1 σ_2 ... σ_t
    任何 n 元置换都可以表示成不交的轮换之积

对换表示式:
    设 S = {1,2,...,n}, σ 是S上的k阶轮换, 那么σ可以进一步表示成对换之积
        (i_1,i_2,...,i_k) = (i_1,i_2)(i_1,i_3)...(i_1,i_k)
    任意 n 元置换都可以表示成对换之积

性质: 
    轮换表示式中的轮换是不交的, 而对换表示式中的轮换是允许有交的, 因此
    轮换表示式是唯一的, 而对换表示式是不唯一的

    可以证明, 同一个n元置换的不同对换表示式中所含对换个数的奇偶性是不变的

奇(偶)置换:
    奇置换: n元置换σ可以表示成奇数个对换之积
    偶置换: n元置换σ可以表示成偶数个对换之积
    在偶置换和奇置换之间存在一一对应, 因此奇置换和偶置换各有n!/2个

n元对称群:
    考虑所有的 n 元置换构成的集合S_n, 任何两个n元置换之积仍旧是n元置换, 所以S_n
    关于置换的乘法是封闭的. 置换的乘法满足结合律. 恒等置换(1)是S_n中的单位元
    对于任何n元置换 σ ∈ S_n, 逆置换 σ^{-1} ∈ S_n是 σ 的逆元
    这就证明了S_n关于置换的乘法构成一个群, 称作n元对称群

n元交错群:
    设A_n是所有的 n 元偶置换集合. 使用子群的判定定理不难证明A_n是S_n的子群
    称作n元交错群

n元置换群:
    S_n的所有子群都称作 n 元置换群, S_n,A_n都是n元置换群的特例

定理10.13(Polya定理):
    设 N = {1,2,...,n}是被着色物体的集合, G = {σ_1,σ_2,...,σ_g}是 N 上的置换群
    用m种颜色对N中的元素进行着色, 则在G的作用下不同的着色方案数是:
        M = ∑m^{c(σ_k)} / |G|, k∈[1,g]
    其中, c(σ_k)是置换σ_k的轮换表示式中包含1阶轮换在内的轮换个数

    idea:
        Polya定理的核心思想建立在Burnside引理上, 并对其进行了推广
        
        Burnside引理提供了一种计算群的轨道数(本质不同的等价类)的方法, 它指出
        轨道数等于群中所有元素的不动点数量的平均值
            轨道数 = ∑|X^g| / |G|, g ∈ G

        Polya的洞察: 一个着色方案被置换σ_k固定, 当且仅当σ_k的每个轮换内部的所有元素
        都染有相同的颜色
            因此, 被σ_k固定的着色方案就是m^{c(σ_k)}
