
下面的恒等式给出了集合运算的主要算律, 其中A,B,C代表任意的集合
集合恒等式:
    (1)幂等律:
        A∪A = A
        A⋂A = A
    (2)结合律:
        (A∪B)∪C = A∪(B∪C)
        (A⋂B)⋂C = A⋂(B⋂C)
    (3)交换律:
        A∪B = B∪A
        A⋂B = B⋂A
    (4)分配律:
        A∪(B⋂C) = (A⋂B)∪(A⋂C)
        A⋂(B∪C) = (A∪B)⋂(A∪C)
    (5)同一律:
        A∪∅ = A
        A⋂E = A
    (6)零律:
        A∪E = E
        A⋂∅ = ∅
    (7)排中律:
        A∪~A = E
    (8)矛盾律:
        A⋂~A = ∅
    (9)吸收律:
        A∪(A⋂B) = A
        A⋂(A∪B) = A
    (10)德摩根律:
        A-(B∪C) = (A-B)⋂(A-C)
        A-(B⋂C) = (A-B)∪(A-C)
        ~(B∪C) = ~B ⋂ ~C
        ~(B⋂C) = ~B ∪ ~C
        ~∅ = E
        ~E = ∅
    (11)双重否定律:
        ~~A = A

如何证明集合恒等式?
方法一:
    利用命题演算的方法
    例1: 证明A-(B∪C) = (A-B)⋂(A-C)
    证:
        对任意的x, 有:
        x∈A-(B∪C) <==> x∈A∧x∉B∪C
                  <==> x∈A∧¬(x∈B∨x∈C)
                  <==> x∈A∧(¬x∈B∧¬x∈C)
                  <==> x∈A∧x∉B∧x∉C
                  <==> (x∈A∧x∉B)∧(x∈A∧x∉C)
                  <==> x∈A-B ∧ x∈A-C
                  <==> x∈(A-B)⋂(A-C)

    例2: 证明A⋂E = A
    证:
        对任意的x, 有:
        x∈A⋂E <==> x∈A∧x∈E
              <==> x∈A
    以上证明的思想是:
        设P,Q为集合公式, 欲证P = Q, 即证:
            P⊆Q∧Q⊆P为真
        也就是要证对于任意的x有
            x∈P ==> x∈Q 和 x∈Q ==> x∈P
        对于某些恒等式可以将这两个方向的推理合到一起, 就是
            x∈P <==> x∈Q

除了以上算律以外, 还有一些关于集合运算性质的重要结果:
    (1)
        A⋂B⊆A, A⋂B⊆B
    (2)
        A⊆A∪B, B⊆A∪B
    (3)
        A-B⊆A
    (4)
        A-B = A⋂~B
        推论: (A-B)∪B = A∪B
    (5)
        A∪B = B <==> A⊆B <==> A⋂B = A <==> A-B = ∅
    (6)
        A⊕B = B⊕A
    (7)
        (A⊕B)⊕C = A⊕(B⊕C)
    (8)
        A⊕∅ = A
    (9)
        A⊕A = ∅
    (10)
        A⊕B = A⊕C ==> B = C

    证明(1):
        对任意的x, 有:
            x∈A⋂B ==> x∈A∧x∈B
                  ==> x∈A

            x∈A∪B ==> x∈A∧x∈B
                  ==> x∈B
    证明(2):
        对任意的x, 有:
            x∈A ==> x∈A∨x∈B
            x∈B ==> x∈A∨x∈B
    证明(3):
        对任意的x, 有:
            x∈A-B ==> x∈A∧x∉B
                  ==> x∈A
    证明(4):
        对任意的x, 有:
            x∈A-B <==> x∈A∧x∉B
                  <==> x∈A∧x∈~B
                  <==> x∈A⋂~B

    证明(5):
        先证: A∪B = B ==> A⊆B
        对任意的x, 有:
            x∈A ==> x∈A∨x∈B
                ==> x∈A∪B
                ==> x∈B (A∪B = B)
        再证: A⊆B ==> A⋂B = A
        由性质(1), A⋂B⊆A, 下证A⊆A⋂B
        对任意的x, 有:
            x∈A ==> x∈A∧x∈A
                ==> x∈A∧x∈B
                ==> x∈A⋂B
        **接着证: A⋂B = A ==> A-B = ∅
            A-B = A⋂~B
                = (A⋂B)⋂~B
                = A⋂(B⋂~B)
                = A⋂∅
                = ∅
        最后证: A-B = ∅ ==> A∪B = B
            A∪B = (A-B)∪B (性质4推论)
                = ∅∪B
                = B
