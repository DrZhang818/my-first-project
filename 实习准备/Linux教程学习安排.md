# Linux 教程学习安排

更新：2026-09-20。对应《实习准备计划》第 1 阶段，并与第 4、9 阶段衔接。不按天数或视频时长安排，以独立完成练习为标准。

教材：[颢天：只学够用的 Linux：零基础最小入门教程](https://www.zouht.com/4399.html)。本安排根据文字版目录和相关内容制定，未评价配套视频的讲解质量。下列练习和验收是为你的 C++ 实习准备另行设计的。

## 为什么加入

原计划是能力清单，适合检查进度，但对第一次接触 Linux 的人，缺少从概念到实际操作的教学过程。这份教程可以作为命令行入门教材。操作系统原理、网络协议、C++ 构建调试仍按主计划学习。

现有清单已经勾选到编译流程，因此采用“先自检，哪里不熟补哪里”。不因新增教材而重置学习进度，也不以看完全部视频为目标。

## 每一小节怎样学

1. 先写下本节要解决的问题，例如“如何找到刚才保存的文件”。暂时说不出用途时，先看例子或让我解释场景。
2. 阅读对应文字；不理解操作过程时，再看对应视频片段。熟悉内容直接做验收，不强制重复看视频。
3. 在自己的练习目录动手，修改文件名、路径或输入，观察结果是否符合预期。
4. 合上教程，独立完成一个小任务；允许查帮助，不要求背参数。
5. 用三句话记录：解决了什么问题、用了什么办法、怎样确认成功。

遇到新概念，先分清它属于 Shell 使用、操作系统还是计算机网络。如果它依赖后面的课程，记下并按下面的衔接安排处理，不在当前章节无限扩展。

## 第一轮：补齐现在需要的能力

表中章节编号对应上述教材；学习顺序按当前需求重新安排。

| 顺序 | 选读范围 | 要解决的问题 | 自己完成的验收 |
| --- | --- | --- | --- |
| A 基础自检 | 1.1～1.6 | 我在哪里，文件在哪里，怎样查看和修改？ | 新建练习目录，创建文本，复制并重命名；从另一个目录用相对路径和绝对路径分别访问它；解释两个路径为何都有效。会做即可跳过对应内容。 |
| B 输入输出与权限 | 1.7～1.8、2.3 | 怎样给程序提供输入、保存结果、筛选文本，怎样解释权限错误？ | 用自己的 C++ 程序读取 input.txt，把正常输出与错误输出分别保存；从自建日志中筛选含 ERROR 的行；查看并修改一个自建文件的权限，说明改了谁的哪种权限。 |
| C 安装与环境 | 1.9、1.11、2.8～2.9 | 工具从哪里来，为什么有时找不到命令，配置在哪里生效？ | 确认编译器是否可用并查看版本，缺少时再安装；解释 ./main 的路径含义；设置一个自定义环境变量，让子程序读到，再在另一个独立打开的终端比较结果。 |
| D 运行与观察 | 2.5～2.6 的任务和 CPU／内存部分，另外补 ps | 程序还在不在，正在执行还是等待，怎样暂停、继续和结束？ | 启动自己的一项长时间任务，找到 PID；观察状态和资源占用；暂停、恢复、结束后再查询；解释任务编号与 PID、暂停与退出的区别。 |
| E 文件交付与空间 | 2.2，以及 2.6 的 du／df 部分 | 怎样打包练习成果，怎样查目录占用和剩余空间？ | 把自己的源码、测试输入和说明打包，在新目录解压，确认文件齐全；分别查询练习目录占用和所在文件系统可用空间，说明两项结果为何不同。 |

学习深度由下面的限制控制：

- 编辑器先选一个，能打开、修改、保存、退出即可。Vim 的复杂操作不影响当前进度。
- 文本处理先完成查找、筛选、计数任务。sed 先会一个简单替换，复杂正则和脚本以后按需补。
- 环境配置先理解变量传递、命令查找和当前终端／新终端的区别。动态库搜索先知道用途，等实际构建出现相关问题再深入。
- 进程观察先关注 PID、状态、CPU 和内存。调度优先级、完整内存指标等内容留给操作系统阶段。
- 后台任务先做完暂停、继续、结束。tmux 只需会建立、离开和重新进入会话；暂时用不到时可后补。
- 文件练习统一在自己新建的专用目录中进行。权限实验只改自己的练习文件。

## 与原实习计划的关系

本教程负责帮助你熟练使用 Linux。主计划第 3 阶段解释进程、线程、虚拟内存等原理；第 4 阶段解释网络通信；第 5 阶段练习网络编程。学习这些内容时再回到 Linux 观察现象。

第一轮通过后，继续当前主线：Git → CMake → GDB → 第 1 阶段综合练习。不要等待第二轮和工具索引全部学完。

## 你现在的下一步

先做 A 的验收：在家目录下新建一个尚不存在的练习目录，建立 notes 和 backup 两个子目录；在 notes 中写一份简短笔记，复制到 backup 并改名；切换到 backup，用相对路径查看 notes 中的原笔记，再用绝对路径查看一次。

把实际使用的命令和输出保留下来，并解释每个路径从哪里开始计算。如果独立完成，就不重看文件操作部分，接着做 B 的验收。卡在哪里，才回看对应小节。

这项练习只判断需要从哪里补起，不撤销你在主计划中已经记录的完成状态。
